# skills

A collection of AI agent skills that I've found useful.

## Usage

The [skills.sh](https://www.skills.sh/) tool can be used to help with SKILL configuration for your tooling of choice.

### right-to-left

Instructions for how to make interactivity and Tailwind styling work with right-to-left (rtl) languages.

Helpful for migrating existing left-to-right oriented codebases or instructing the agent how to build new frontend elements in a right-to-left friendly way.

```sh
npx skills add https://github.com/ben-basten/skills --skill right-to-left
```
